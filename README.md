One funny single-line developer excuse for when code breaks in production, written by a small deterministic TypeScript program to `/output/entry.txt`. The program composes the line from three named parts, checks it against the 1–200 character single-line gate, writes it, and verifies the write by reading it back.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
